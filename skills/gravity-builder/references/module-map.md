# Module Map

- `src/core/interface`: external adapters (Telegram, WS, voice)
- `src/core/orchestrator`: routing/lifecycle/delegation
- `src/core/runtime`: context assembly and reasoning loop
- `src/core/providers`: provider adapters and registry
- `src/core/tools`: registry, policy, and sandbox wrappers
- `src/core/memory`: SQLite schema and repositories
- `src/core/forge`: self-improvement scaffolding
